# Repository file map: which file means what

> This file is generated by `tools/clrs_docs_generate.py` from the repository and the training outputs; do not edit it by hand. Re-run the generator after any change to the data.


The repository has 350 tracked files (listed by `git ls-files`). This document describes every one of them. Roles: **runtime** (used when the site runs), **build** (used to build the image or the data), **analysis** (scripts and results of the research), **test** (checks), **docs**, **ci** (GitHub Actions).

The column "in image" says whether the file is copied into the Docker image (everything except what `.dockerignore` excludes). Model bundles (`models/`) and the Python caches are created inside the image and are not tracked.

## How the pieces fit together

```text
browser                     server (port 8766, server_128.py)                 data on disk
-------                     ---------------------------------                 ------------
viewer3.html  <---------    GET /            (page with build id filled in)   viewer3.html
explain.js, attrview.js,    GET /<script>?v=BUILD  (gzip, immutable cache)    *.js
mpnn.js, attrib.js,
clrs-edge-attrib.js,
mpnn_worker.js
Web Worker  <-----------    GET /models/<algo>.json|bin?v=BUILD               models/ (made at image build by model_export.py from checkpoints_v3/)
                            GET /edge_tc/<algo>.bin|json|latents.json         edge_tc/ (made by clrs_export_edge_tc.py + clrs_edge_latents.js)
                            GET /api/instance?algo&n&p&seed&v=BUILD           CLRS sampler (jax-free path through model_export.build_instance)
                            GET /api/weights, /api/feature_labels (demo)      algos/<algo>/*
                            GET /api/contexts (demo)                          runs the JAX model: top-activating examples
                            GET /api/graph (fallback)                         runs the JAX model for one graph
port 8080 (8767 in the container): fig47/static_server.py                     fig47/ (plain files)
```
